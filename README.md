# Basic HTML Website - roadmap.sh Project

This project is an implementation of the [Basic HTML Website](https://roadmap.sh/projects/basic-html-website) challenge from roadmap.sh. The goal of this project is to teach you how to structure a website using HTML i.e. different sections of a website like header, footer, navigation, main content, sidebars etc. Do not style the website, only focus on the structure. Styling will be done in separate projects.

## ✨ Features & Project Requirements
- **Semantic HTML:** Utilizes proper structural elements such as `<header>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **SEO Optimization:** Equipped with optimized meta tags for description, author, and page title.
-  **4 File HTML:** The website should have the following pages : index.html, articles.html, projects.html, and contact.html`.
- **Navigation:** The website should have a navigation bar that should be present on all pages and link to all the pages.

## 🛠️ How to Run the Project Locally
1. Clone or download this repository to your local computer: (https://github.com/mtyadfn/basic-html-website)
2. Open the project folder.
3. Open the `index.html` file using your web browser or run it via the *Live Server* extension in VS Code.
